# Révision AWS Certified Cloud Practitioner (CLF-C02)

Application web statique pour préparer l'examen **AWS CLF-C02**, en français.

- 29 chapitres, chacun en 3 niveaux (zéro, examen, pro).
- 443 questions de chapitres et un examen blanc de 71 questions, avec une explication pour chaque option.
- Fiches par domaine, pièges fréquents, cartes mémoire.

Ouvrir `index.html` dans un navigateur.
